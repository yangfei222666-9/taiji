## Evidence State Rules

| State | Meaning |
| --- | --- |
| PASS | Source is real, located, reviewable, and safe for the current scope |
| PARTIAL | Source exists but has incomplete context, privacy gaps, or limited relevance |
| PENDING | Source has not been reviewed or indexed yet |
| BLOCKED | Source includes secrets, private data, unsafe content, or unsupported claims |
