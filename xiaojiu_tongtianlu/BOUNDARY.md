# Xiaojiu Tongtianlu Boundary

## Verdict

```text
verdict=xiaojiu_tongtianlu_boundary_draft
scope=personal_growth_archive_boundary
mode=docs_only_privacy_and_overclaim_boundary
canonical_truth=PENDING
runtime_changed=false
code_changed=false
secret_read=false
stage_commit_push=false
repo_pass_claimed=false
t7_imported=false
```

## Purpose

Xiaojiu Tongtianlu is the long-term record of the operator's real learning path, TaijiOS evolution, AI-assisted engineering practice, XuanShu mapping, and SpaceX-level engineering ambition.

It may later support essays, timelines, films, AI short dramas, or visual story material, but the evidence layer must remain separate from symbolic and cinematic layers.

## Three-Layer Model

| Layer | Purpose | Boundary |
| --- | --- | --- |
| Real evidence layer | records real events, commits, artifacts, tests, closeouts, and verified milestones | must be factual, source-backed, and privacy-reviewed |
| Symbolic layer | maps real events into Journey to the West, I Ching, XuanShu, and Hidden Systems language | metaphor only; not scientific proof or readiness claim |
| Cinematic layer | dramatizes the journey for film, short drama, or narrative presentation | must be labeled dramatized when fictionalized |

## Hard Rules

No fabricated achievements.

No claim of SpaceX employment, SpaceX readiness, SpaceX access, SpaceX endorsement, SpaceXAI endorsement, or external recognition unless independently verifiable and explicitly sourced.

No secret values, private credentials, tokens, API keys, seed phrases, private keys, passwords, `.env` contents, or keychain material.

No private third-party identity exposure without explicit permission and review.

No sensitive personal data should be placed into canonical repo docs unless the human owner explicitly approves the exact content and destination.

AI-generated scenes, dialogue, visuals, and compressed narratives must be labeled as dramatized or generated when they are not direct records.

Local notes, chat outputs, drafts, screenshots, and output artifacts are not canonical truth until committed, merged, and verified through the relevant repo gate.

## Evidence Requirements

Claims in the real evidence layer should point to at least one of:

```text
git commit
PR
issue
test output
artifact manifest
event_flow.jsonl
closeout.md
timestamped non-secret note
public repo link
```

If a claim has no source, it remains:

```text
verdict=PENDING
claim_type=memory_or_draft
```

## Allowed Material

Allowed after review:

```text
public project milestones
non-secret learning reflections
repo history summaries
closeout summaries
XuanShu symbolic mappings labeled as symbolic
SpaceX career planning labeled as planning only
```

## Blocked Material

Blocked by default:

```text
secret values
credential migration notes containing values
private identities
medical/legal/financial sensitive details
unverified employment or readiness claims
third-party private conversations
raw chat logs with sensitive content
```

## Non-Claims

Xiaojiu Tongtianlu does not claim:

```text
SpaceX readiness
employment readiness
production readiness
repo-level PASS
secret migration complete
external approval
scientific truth from symbolic mapping
```

## Acceptance Criteria

A Xiaojiu Tongtianlu entry is acceptable only if it separates:

```text
what happened
what evidence supports it
what is symbolic interpretation
what is dramatized
what cannot be claimed
```
