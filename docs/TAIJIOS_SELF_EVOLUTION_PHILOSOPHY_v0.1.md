TaijiOS does not assert that the universe is literally code. That claim is not
verifiable inside the system and must remain outside operational authority.

TaijiOS may use the state-machine metaphor as system philosophy: workflows can
be modeled as evolving state streams, human decisions can select branches, and
verified evidence can become durable memory for later correction.

## First Principle

```text
Every intelligent system must evolve, but no system should evolve without evidence, boundaries, and memory.
```

Chinese operator form:

```text
一切智能系统都必须进化，但任何进化都不能脱离证据、边界与记忆。
```

This principle is allowed as TaijiOS philosophy. It is not a metaphysical proof,
trade signal, promotion rule, or runtime permission.

## Core Model

TaijiOS treats reality-like workflows as evolving state streams:

```text
universe_like_runtime -> not claimed as literal truth
current_state -> observed workflow state
future_state -> candidate paths
human_decision -> branch selector
operator_confirmation -> authority gate
evidence -> path memory
verifier -> path validity check
closeout -> path outcome record
self_improvement -> path selection update
```

The future is not a single fixed result in this model. It is a set of candidate
paths that may converge or diverge as inputs, choices, and evidence change.

## Taiji As Bounded Change

Taiji is treated as a philosophy of bounded change:

```text
imbalance -> feedback -> correction -> new_state -> renewed_imbalance -> next_correction
```

Engineering translation:

```text
Taiji is not prediction. Taiji is adaptive correction through evidence, feedback, and bounded change.
```

Chinese operator form:

```text
太极不是算命，而是通过证据、反馈和边界，让系统持续回正并进化。
```

## Why Fake Pass Is Causal Pollution

Fake pass means the system writes an incomplete or false state into memory.
Once that happens, later decisions inherit polluted context.

In TaijiOS terms:

```text
fake_pass = false_state_written_to_memory
false_state_written_to_memory -> future_path_pollution
future_path_pollution -> unsafe_or_wrong_decisions
```

Therefore:

```text
PARTIAL must not be written as PASS
BLOCKED must not be written as FAILED
scope PASS must not be written as repo PASS
provider output must not be written as verified truth
```

This is not cosmetic caution. It protects the causal chain.
