# Symbol To System Map

## Purpose

Translate symbolic study language into engineering and TaijiOS audit language without turning symbols into scientific facts.

Authority: `learning_only`, `observe_only`, and `research_only`.

## Core Map

| Symbol | System translation | Boundary |
| --- | --- | --- |
| Dapin Tianxian Jue | long-term learning and evolution protocol | practice metaphor only |
| Seventy-two transformations | engineering skill stack | skills still need tests and evidence |
| Somersault Cloud | AI acceleration | speed does not equal truth |
| Golden Cudgel | TaijiOS / Evidence Kernel | evidence tool, not magic authority |
| Five Elements Mountain | real-world blockers | blockers must be named and fixed |
| Journey to obtain scriptures | 10-20 year SpaceX engineer path | metaphor, not readiness claim |
| Hexagram | system state | observation tag only |
| Changing line | state transition | hypothesis until evidence |
| Original hexagram | current condition | must be grounded in real facts |
| Changed hexagram | possible evolution | scenario, not prediction guarantee |
| Auspicious / inauspicious | risk verdict | requires explicit evidence to become decision |
| Timing / position | context | must include concrete date, actor, system state |

## Engineering Translation Rules

1. Translate symbol into a bounded system claim.
2. State what evidence would validate it.
3. State what cannot be claimed.
4. Keep the result below judgment, trade, medical, legal, and public-claim authority.
5. Close the loop after real-world evidence appears.

## Examples

### Golden Cudgel

Symbolic reading:

- concentrated force
- controllable power
- tool that obeys trained mind

System reading:

- TaijiOS / Evidence Kernel as a force multiplier
- useful only when boundaries and verification exist

Cannot claim:

- tool existence equals runtime truth
- local artifact equals repo pass
- status display equals authority

### Five Elements Mountain

Symbolic reading:

- constraint
- confinement
- boundary before maturity

System reading:

- real blockers: Git truth, C++, Linux, English, compliance, tests, reliability, and evidence

Cannot claim:

- blocked means failed
- local ability means external authority
- desire means readiness

### Somersault Cloud

Symbolic reading:

- speed
- reach
- non-linear movement

System reading:

- AI accelerates search, learning, drafting, and exploration

Cannot claim:

- speed equals correctness
- AI output equals truth
- generated plan equals executed result

## Closeout Vocabulary

Allowed:

- `PASS as metaphor`
- `PENDING as truth`
- `learning_only`
- `observe_only`
- `candidate_only`
- `needs evidence`
- `blocked from execution`

Forbidden:

- `scientifically proven` without scientific evidence
- `trade signal`
- `health advice`
- `legal conclusion`
- `SpaceX readiness`
- `repo-level PASS`
