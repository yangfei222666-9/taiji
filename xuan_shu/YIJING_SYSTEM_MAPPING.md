# I Ching System Mapping

## Verdict

Study path: PASS as long-term research direction.

Authority: `learning_only` and `observe_only`.

This file maps I Ching language into system-state language for TaijiOS study. It does not use I Ching as scientific proof, prediction authority, trading signal, medical advice, legal advice, or high-stakes decision authority.

## Core Position

The I Ching is studied as a change-system language:

- state
- timing
- position
- transition
- risk
- advance
- retreat
- restraint
- transformation

It is not treated as an automatic decision engine.

## Primary Mapping

| I Ching | TaijiOS / systems language |
| --- | --- |
| Hexagram | system state |
| Line | state detail |
| Changing line | state transition |
| Original hexagram | current condition |
| Changed hexagram | possible evolution |
| Auspicious / inauspicious | risk verdict |
| Timing / position | context / timing |
| Favorable to proceed | proceed with boundary |
| Not favorable to proceed | BLOCKED / do not advance |
| Regret / trouble | warning signal |
| No blame | bounded acceptable state |

## First Study Topics

### Yin And Yang

Modern translation:

- polarity
- complementarity
- tension
- balance
- phase relation

TaijiOS use:

- detect overextension
- detect blocked contraction
- avoid single-variable explanations

### Three Powers: Heaven, Earth, Human

Modern translation:

- environment
- structure
- agency

TaijiOS use:

- separate external condition, system constraint, and human choice
- avoid blaming one layer for all outcomes

### Eight Trigrams

Modern translation:

- primitive state types
- environmental modes
- recurring patterns

TaijiOS use:

- classify context before action
- avoid acting from stale state assumptions

### Sixty-Four Hexagrams

Modern translation:

- composite system states
- interaction patterns
- transition contexts

TaijiOS use:

- case study tags
- risk language
- scenario review prompts

### Original And Changed Hexagram

Modern translation:

- current state
- possible evolution

TaijiOS use:

- scenario mapping
- "if this changes, then what changes next?" review

### Timing And Position

Modern translation:

- context-dependent verdict
- phase-sensitive action

TaijiOS use:

- the same action can be PASS, PARTIAL, PENDING, or BLOCKED under different context
- avoid generic advice detached from state

### Auspicious, Inauspicious, Regret, Trouble

Modern translation:

- risk verdict vocabulary
- cost and consequence marker

TaijiOS use:

- convert symbolic risk into explicit blocker or watch item

## Anti-Fake-Hit Rules

- Record the observation before the outcome.
- Define the verification window before closeout.
- Preserve misses.
- Mark vague outputs as `PARTIAL`, `AMBIGUOUS`, or `NOT_VERIFIABLE`.
- Never upgrade intuition into `PASS`.
- Never use I Ching output for trading, medical, legal, or safety-critical decisions.
